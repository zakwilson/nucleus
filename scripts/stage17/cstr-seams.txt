# Stage 17 --strict-cstr seam list.
#
# The closed enumeration from design/stage17-native-strings/overview.md §2.7:
# the places where a C string is the correct type because the other side of the
# call is C. Everything NOT listed here is residual and is reported by
# `nucleusc --strict-cstr`. Additions are reviewable diffs, which is the point —
# the C8 claim ("no non-FFI C strings left") is only as good as this file.
#
# Lines are `<keyword> <name>`:
#   seam         <name>    this callee is a C-interop seam
#   seam-prefix  <name>    …and so is every callee whose name starts with it
#   strptr       <name>    produces a `ptr` that is really a string; the types
#                          cannot see it, so it is named here (phase C7)
#   cfn          <name>    a libc string function. The C-header importer lowers
#                          `char *` to bare `ptr` — `declare i32 @strcmp(ptr,
#                          ptr)` — so these carry no CStr for the signature walk
#                          to find and only a name reaches them (phase C6)
#
# Deleted at C8 with the flag.

# --- The LLVM C API, whole (src/llvm.nuch). ------------------------------
seam-prefix LLVM

# --- Process and environment entry points. -------------------------------
seam getenv
seam system
seam execv
seam execvp
seam popen
seam pclose
seam perror
seam exit
seam abort
seam access
seam unlink
seam mkstemp
seam isatty
seam signal
seam opendir
seam readdir
seam closedir
seam dlopen
seam dlsym
seam dlerror

# --- stdio, for the seams that remain FILE*-shaped. -----------------------
# `fwrite`/`fread` are the two halves of `emit-flush`/`emit-all` and the
# `clang -E` pipe; `snprintf` is the float printer (overview.md §2.6).
seam fwrite
seam fread
seam fflush
seam setvbuf
seam snprintf

# --- The `ptr`-as-string substrate, phase C7. -----------------------------
# These have no CStr in their signatures — they are the interned-string layer
# the whole compiler is threaded on — so nothing but this list finds them.
strptr intern-str
strptr arena-strdup
strptr arena-strndup

# --- libc's string functions, phase C6. -----------------------------------
# Every one of these is residue by definition: it exists to do to a `char*`
# what `StrView`/`String`/`Symbol` do natively. None is ever a seam, so none
# moves to the `seam` list — they leave by their call sites being deleted.
cfn strcmp

cfn strncasecmp
cfn strlen
cfn strnlen
cfn strchr
cfn strrchr
cfn strstr
cfn strdup
cfn strndup
cfn strcpy
cfn strncpy
cfn strcat
cfn strncat
cfn strtol
cfn strtoul
cfn strtoull
cfn strtod
cfn atoi
cfn atol
cfn sprintf
cfn sscanf
